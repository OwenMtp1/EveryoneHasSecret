# Textures

Textures issues des exemples Three.js r170 (`examples/textures`) : parquet (`hardwood2_*`), brique (`brick_*`),
carrelage (`FloorsCheckerboard_*`), herbe (`grasslight-big`), eau (`Water_1_M_Normal`) et ciel HDR de nuit
(`moonless_golf_1k.hdr`, Poly Haven, CC0). Les autres matériaux (papiers peints, marbre, béton, gravier,
tissus) sont générés par code (`src/client/three/materials.ts`).
