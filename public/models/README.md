# Modèles 3D — étape 1 (provisoire)

| Fichier | Origine | Usage |
|---|---|---|
| `Man.glb` | exemples Three.js r170 (`readyplayer.me.glb`, avatar Ready Player Me) | apparence masculine |
| `Woman.glb` | exemples Three.js r170 (`Michelle.glb`, personnage Mixamo) | apparence féminine |
| `Animations.glb` | exemples Three.js r170 (`Xbot.glb`, mannequin Mixamo) | clips idle / walk / run, transférés sur les deux squelettes au chargement |

⚠️ Ces modèles servent au prototype. Leur licence (Mixamo / Ready Player Me) doit être validée avant
toute diffusion publique. L'étape 2 du backlog les remplace par des humains MakeHuman (CC0) générés
via un pipeline Blender, avec coiffures et tenues modulaires sur un squelette commun.

Le jeu fonctionne sans ces fichiers : le personnage procédural sert de repli.
